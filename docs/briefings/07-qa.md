# Briefing — Otimização e QA (Sonnet · `feat/qa` · onda 4)

## A ideia
Antes de o escritório usar o sistema para emitir dossiês de verdade, alguém independente das outras sessões precisa provar que ele **dá os mesmos resultados que o trabalho manual**, que cada perfil só vê o que pode, e que aguenta o volume real.

## Entrega
- Regressão contra dossiês históricos **anonimizados fora do repositório** (só o resultado anonimizado entra como fixture).
- Casos de borda: feriado, semana em andamento, CPF ausente, homônimos, almoço, check-out automático, origem com formato alterado.
- Testes de permissão por perfil (humor, "Doente", motivo de falta, CPF completo).
- Desempenho: painel < 2 s com 1.000 colaboradores × 60 dias; carga diária dentro da janela da madrugada.
- Revisão de segurança (OWASP, LGPD, segredos, logs sem dado sensível).

## Não faz
Não guarda dossiê real no repositório; não corrige código das outras áreas sem PR na branch da área.

## Encaixe
Última onda; abre achados para as sessões donas de cada área.

## Pronto quando
Relatório de QA com achados priorizados e todos os críticos resolvidos.
